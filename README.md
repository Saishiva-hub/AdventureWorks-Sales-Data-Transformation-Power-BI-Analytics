# AdventureWorks-Sales-Data-Transformation-Power-BI-Analytics
Power BI project focused on transforming and combining AdventureWorks sales data from Europe and North America using Power Query, and preparing the data for business intelligence reporting and dashboard development.

## Project Overview

This project is an interactive sales analytics dashboard
created using Microsoft Power BI.

## Objective

The objective is to analyze sales performance, revenue,
customers, products, and regional performance.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel/CSV
- Data Visualization

## Project Workflow

1. Import sales data from Excel
2. Load Europe and North America sales data
3. Clean and transform data using Power Query
4. Remove unnecessary columns
5. Rename and organize columns
6. Append Europe and North America tables
7. Import Country Code data
8. Merge Country Code with the sales data
9. Create the final transformed dataset
10. Save the Power BI project
    
## Key Analysis

- Sales data by country
- Sales Territory analysis
- Product category analysis
- Product sub-category analysis
- Product-level sales analysis
- Country Code analysis
