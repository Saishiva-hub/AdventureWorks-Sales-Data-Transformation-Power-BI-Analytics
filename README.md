# AdventureWorks-Sales-Data-Transformation-Power-BI-Analytics
Power BI project focused on transforming and combining AdventureWorks sales data from Europe and North America using Power Query, and preparing the data for business intelligence reporting and dashboard development.

## Project Overview

This project is an interactive sales analytics dashboard
created using Microsoft Power BI.

## Objective

The objective is to analyze sales performance, revenue,
customers, products, and regional performance.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel/CSV
- Data Visualization

## Project Workflow

1. Import dataset
2. Clean data using Power Query
3. Create relationships between tables
4. Build data model
5. Create DAX measures
6. Create interactive dashboard
7. Analyze business insights

## Key Analysis

- Total Sales
- Total Profit
- Sales by Region
- Sales by Product
- Monthly Sales Trend
- Top Customers
- Profit Analysis
